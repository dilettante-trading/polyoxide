# CLOB RFQ (Request for Quote)

Base URL: `https://clob.polymarket.com`

> Note: RFQ endpoints are not fully documented in Polymarket's public API docs. Schema derived from observed API behavior.

## Create RFQ Request

`POST /rfq/request`

**Auth:** L2

## Cancel RFQ Request

`DELETE /rfq/request`

**Auth:** L2

## Create RFQ Quote

`POST /rfq/quote`

**Auth:** L2

## Cancel RFQ Quote

`DELETE /rfq/quote`

**Auth:** L2

## List Quotes

`GET /rfq/quotes`

**Auth:** L2

## List Requests

`GET /rfq/requests`

**Auth:** L2

## Get RFQ Prices

`GET /rfq/prices`

**Auth:** L2
